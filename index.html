darktable on your phone.

A touch-friendly Android photo editor built on darktable's own processing engine.

Droidtable reuses darktable's original processing modules instead of reimplementing them, and reads and writes the same XMP sidecar files as desktop darktable — so your edits move seamlessly between desktop and phone.

How it works

  • Kotlin + Jetpack Compose UI — Lighttable and Darkroom views designed for touch, smartphone first with a tablet layout built in.
  • Separate engine process — the native engine runs in its own Android process behind a versioned Binder IPC contract; a crash there never kills the UI.
  • The real darktable engine — libdarktable built for Android without GTK, with all 93 original processing modules, verified against desktop darktable within measured tolerances.
  • Desktop-compatible sidecars — RAW files open with their <name>.xmp automatically, and saving writes the same XMP format desktop darktable reloads.

Status

The Android engine port is complete and verified on real hardware: it renders desktop edits bit-close to desktop darktable (within the project's measured ARM tolerance policy) and round-trips XMP sidecars with desktop. The editing UI — Lighttable, Darkroom, histogram, and a growing set of modules — is in active development.

This site is just getting started. More documentation, screenshots and downloads will appear here as the project matures.
