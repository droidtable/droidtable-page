# Branding assets

Logo and icon files for the Droidtable page. Source of truth lives in the app
repository under `branding/` (SVG masters + `tools/Render-Branding.ps1`); the
files here are copies for the website.

- `droidtable-mark.svg` — mark on transparent background (100x100 viewBox)
- `droidtable-icon.svg` — rounded-square app icon (dark `#0d1117` background)
- `droidtable-logo-dark.svg` / `droidtable-logo-light.svg` — mark + wordmark
  (wordmark drawn as paths, no font needed) for dark / light backgrounds
- `droidtable-mark-16/32/48/512.png` — favicons and general use
- `apple-touch-icon-180.png` — rendered from `droidtable-icon.svg` at 180x180
- `droidtable-logo-dark-440x112.png`, `droidtable-logo-dark-880x224.png` —
  rendered wordmarks
- `droidtable-og-1200x630.png` — social share image (logo on `#0d1117`)

Palette: robot `#3fb950`, eyes/background `#0d1117`, table frame `#30363d`,
lighttable surface `#e6edf3`, slides `#58a6ff`.

All files in this directory are dedicated to the public domain under
**CC0 1.0 Universal** — see [CC0-1.0.txt](CC0-1.0.txt). Original design, no
third-party artwork or fonts; does not reuse darktable's or Google's logos.
